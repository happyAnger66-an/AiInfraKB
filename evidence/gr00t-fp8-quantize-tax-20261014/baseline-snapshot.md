# GR00T FP8 baseline snapshot（phase_ada_ln）

- 日期：2026-10-14（Asia/Shanghai）
- **Standing rule**：任何 baseline bump 须同时交付 (1) 分阶段+全链路 e2e 时延 (2) overall + per-dim0–31 cos/mse/mean_abs。**仅 denoise 不够。**
- Thor 锁频：gpc=1575 MHz / nvd=1692 MHz；`thor_bench_gate` PASS
- 测法：hybrid `bench_hybrid_stages_ada_ln.py` — bb=`vit_llm_flash_unirt`（FP16）+ DiT 包；warmup=8 iters=40；墙钟含 H2D/D2H；LLM 输入随机（无 host scatter）
- FP16 基线 DiT：`gr00t_n17_xdof_fp16_temb_fix_unirt`
- FP8 DiT：`gr00t_n17_dit_fp8_full_dit_phase_ada_ln_unirt`（A+B+LN+ada_ln_fp8）
- 精度：action_head 对拍 vs PT；门限 cos≥0.999 mse<1e-4
