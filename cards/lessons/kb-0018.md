## 结论

来源：牛马 DitSoftAdd scout；AdaStatic 后补捕 denoise_loop nsys。**未改代码、未编 pack、未跑 A/B。** 架构口径 **SOFT-GO，默认不合**。

Softmax+cast 已是 `fused_softmax_cast`（**2.40 ms/loop**），再写一个 soft+cast 收益约 0。它和 residual **add2（1.39）** 中间隔着 **PV（probs@V，0.79）→ permute/reshape → quantize?+to_out**，不是相邻 launch，TVM 再融一行 `op.add` 吃不掉 softmax。

正道：FlashRT/synapsex 新核 **`residual_add_layer_norm_fp8`**（`y = LN(residual + attn_out) → e4m3`；DiT 是 LayerNorm，不能搬 π0 RMS residual），或 **to_out FP8 GEMM residual epi**。修订估 **−0.2～−0.8 ms**（inventory −0.3～−1.0 略偏乐观）。相对 gap ~28.8 ms 是填缝，不当主刀。

可泛化：先钉「已融」和「中间隔了谁」再谈再融；不相邻的两段 launch 不能靠 Relax fuse 一行消掉。

## 适用条件

- 硬件：Thor；基线 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic（e2e_full 95.513）。
- 模型：GR00T DiT denoise（`DIT_LAYOUT=0`；matmul 路径）。
- nsys：GPU ~46.6 ms/loop；ada bank nvjet 已为 0。
- 未验证：新核落地后的 same-session Δ 与 gate。to_out residual epi 与 DitAttnE4 可能打架，二选一。

## 证据

见 `evidence/gr00t-ditsoftadd-20261015/`。本卡写下时无最小 wire。Soft「无核 / 默认不合」已被 **kb-0023** GO merge 取代（`flashrt.res_ln_fp8` glue；e2e_full **87.506**）。softmax 已融、与 residual add 不相邻仍然成立。

## Don'ts

1. 勿碰 QK dtype；勿重放 **AttnScore**。
2. 勿把 PV（wmma / nvjet_64×48）算进「只融 residual add」。
3. 勿搬 π0 `gated_res` / RMS residual——DiT 是 LayerNorm + AdaLN。
4. 勿重开 DitAttnE4 / DitLayout / L2 / V1 / VisNonV1。
5. 勿在没有 `residual_add_layer_norm_fp8`（或 to_out residual epi）可编 pack 时合入。
