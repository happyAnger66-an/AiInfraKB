## 结论

来源：牛马 LlmRmsQ scout + merge；架构师升 GO 批合并锁基线。

路径：`input_layernorm`→FlashRT `rms_fp8`→q/k/v `forward_prequantized`。scout 相对 L3+AdaStatic：**e2e −2.02 / llm −1.64**；合入 sanity **e2e_full 98.432**（−1.75）、mse **1.465e-4**（比 scout 贴门更松）。nsys：QKV nvjet 清零，入口税换 `rms_fp8`。

与 **L2** 硬边界：L2 = RMS FP16 + 独立 `quantize_fp8`（NO-GO）；本刀 = RMS 直出 e4m3 共享进 QKV。

可泛化：QKV FP8 成败看入口税形态；合入后以 sanity 墙钟为权威基线。

## 适用条件

- 硬件：Thor；合入栈 L1+L3+LlmRmsQ+D1+crosskv+D1take+AdaStatic。
- bb 别名：`gr00t_n17_bb_fp8_baseline_L1L3LlmRmsQ_unirt`。
- `w−1` Soft-GO 可跟，本轮不挖。
- 下一刀：EncFp8 scout（禁 L2/V1/AttnScore/DitAttnE4 核债重开）。

## 证据

见 `evidence/gr00t-llmrmsq-20261015/`（summary + scout + merge）。

## Don'ts

1. 勿重放 **L2 plain QKV**；勿把本刀写成 L2 重开。
2. 勿只用 scout 数字当基线——权威是 merge e2e_full **98.432**。
3. 勿自批 Silu epi / Vision Soft-GO / DitAttnE4 核债。
4. 勿用 denoise_loop 会话噪声否决（权威 e2e_full / backbone_llm）。
