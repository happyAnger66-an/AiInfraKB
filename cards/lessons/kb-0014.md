## 结论

来源：牛马 VisNonV1 scout；架构师批 **NO-GO，不合**。

相对同 session L3+AdaStatic ref：embed **19.52→20.89（+1.37）**、e2e_full **99.64→101.12（+1.48）**；inventory 估 −2～−5 **符号相反**。overall gate PASS（cos 0.999966 / mse 8.13e-5）；embed feature cos ~0.99 soft。

nsys：shared-Q 路径 **HIT**；独立 `quantize_fp8` ~0.57 ms/iter + FP8 cutlass 打不过基线 fused-f16 nvjet。与 V1 plain **同病不同灶**（税在 attn Linear，不在 MLP）。

可泛化：Vision FP8 成败看能否 **杀掉独立 Q launch / 保住 fused epi**；接线正确不等于速度正。续挖优先 π0 `res_ln_fp8` / `vit_fp8_o_half_in`，勿再加 plain Linear。

## 适用条件

- 硬件：Thor；基线 L1+L3+D1+crosskv+D1take+AdaStatic。
- 模型：GR00T ViT embed（UniRT/MLC）；preset `e4m3_gr00t_llm_l3_vit_attn`。
- 未动：ViT MLP、DitAttnE4、LlmRmsQ。
- 未验证：`res_ln_fp8` / `o_half_in` 实测。

## 证据

见 `evidence/gr00t-visnonv1-20261015/`。架构师：下一刀 **LlmRmsQ**（禁重放 L2/V1）；Vision Soft-GO backlog 本轮不抢。

## Don'ts

1. 勿合入 VisNonV1 / 勿重放 V1/V1b MLP。
2. 勿只看 overall PASS 合速度负向刀。
3. 勿再加 plain Linear 当 Vision 主路径；须先清 Q 税。
4. 勿把本结论写成「Vision FP8 永不可行」——续挖方向是清税融合，不是放弃。
