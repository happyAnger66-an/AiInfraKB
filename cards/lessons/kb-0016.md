## 结论

来源：牛马 EncFp8 scout + merge；架构师由 Soft-GO 升 GO，批合并锁基线。

路径：`vl_self_attention` 4×BasicTransformerBlock 静态 FP8（QKV / to_out / FFN）+ 现成 glue（QKV-shared / gelu_fp8 / attn-out / FFN_LN_FP8）。scout 相对 L3 隔离：encode **−1.388**、e2e **−0.407**（其它 stage 会话噪声），当时默认不合。合入叠在 LlmRmsQ 上：e2e_full **95.513**（同 session Δ **−2.731**），encode_condition 6.615→5.177（**−1.438**）。DiT 未改，denoise_loop −1.074 / head −1.713 记会话噪声；**刀账以 encode 为准**，权威墙钟以 cand **95.513** 为准。overall cos **0.999999** / mse **2.723e-6** PASS。

可泛化：合入后用 sanity cand 当基线；e2e 若吃到未改舞台的噪声，收益记在被改的 stage。

## 适用条件

- 硬件：Thor；合入栈 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic。
- bb 别名：`gr00t_n17_bb_fp8_baseline_L1L3LlmRmsQEnc_unirt` → `gr00t_n17_bb_fp8_l3_qkv_rmsq_enc_i4_unirt`。
- preset：`e4m3_gr00t_llm_l3_qkv_enc`（136 = L3+QKV 112 + VL-SA 24）。
- commit：mlc-vla `7d9fd34cd3bbd9d71d36413a5775a7aa672aff22`（短 `7d9fd34c`）。
- 未动：state_encoder / vlln；DiT 包不变。
- 距 66.7 仍 ~28.8 ms。

## 证据

见 `evidence/gr00t-encfp8-20261015/`（summary + scout + merge）。

## Don'ts

1. 勿用 denoise_loop 或 e2e Δ **−2.731** 当刀账——刀收益是 encode_condition **−1.438**；权威墙钟是 cand e2e_full **95.513**。
2. 勿把 scout 的 e2e −0.41 写成合入基线。
3. 勿本轮挖 state_encoder / vlln。
4. 勿重放 L2 / V1 / AttnScore / DitAttnE4 核债。
