## 结论

来源：牛马 Vision Soft scout。**未 wire、未编包、不合入。** scout 口径 **Soft-GO**：默认可开 glue+measure，**默认不合入**。架构师在此之上升 **GO glue+measure（in flight）**，合入仍另批。

π0 `res_ln_fp8` + `vit_fp8_o_half_in` **可迁 YES**。GR00T Qwen3 ViT 与 π0 SigLIP 同是 pre-LN residual；hidden **1024** 走通用 `res_ln_fp8_kernel_f16`（`kLnFp8MaxDim=4096`），6×256=**1536** rows 按 row 启动。核已在 mlc-vla FlashRT，不另开新核 epic。目标是杀掉 VisNonV1 已证的独立 `quantize_fp8`（**~0.57 ms/iter**；embed **+1.37** / e2e **+1.48**）并吸收 residual+LN。VisNonV1 上 FP8 GEMM 净值约 **−0.77**，plain 回归来自税和拆融合。

估 Δembed_vision / Δe2e_full **−0～−2.5 ms**（bb-only，同量级）；中枢 **−0.5～−1.5**。锁基线 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi，e2e_full **89.772** / embed_vision **19.338**。晓安哥拍 **B1+B2**；本卡只覆盖 B2。满成 Soft 后 e2e 仍约 **87–90**，冲不满 **66.7**。

可泛化：Vision FP8 要清独立 Q launch（half_in BYOC 吃进 out_proj，res_ln 吃 residual+LN）。可迁是可搬 glue，锁 bb 的 ViT 仍是 FP16，config 还没有这两面 flag。

## 适用条件

- 硬件：Thor；锁基线见上（e2e_full **89.772**）。读码在 LT5；Thor 运行约定 `FLASHRT_ROOT=/srcs/data/FlashRT`。
- 模型：GR00T Qwen3 ViT embed。RoPE / flash 在 attn 内部、`res_ln` 之后。PatchMerger / deepstack 不进本 Soft MVP。
- 验收：overall cos>0.999 且 mse<0.0005；另报 embed feature cos（real-act calib，目标尽量 ≥0.99）。墙钟 lockfreq，warmup≥8 / iters≥40。
- glue 清单：`VisionBlock.forward_fused`、`forward_from_prequant`、`_out_proj` half_in、全层 FP8Linear preset、`vit_fp8_res_ln` / `vit_fp8_o_half_in`。新 pack 名，不覆盖锁 bb alias。
- 未验证：glue 后的 same-session Δ 与 nsys HIT（`quantize_fp8` ~0、`res_ln_fp8` 替换 `layer_norm_kernel`、out_proj BiasFromHalf）。合入门槛 scout 建议 embed ≤ −0.5 且 overall PASS，尚未按数批合。
- V1b（`vit_fp8_fc1_gelu_q_epi`，历史 embed −0.8～−0.9）可后叠，不是本刀必做。

## 证据

见 `evidence/gr00t-vision-soft-20261015/`（summary + scout 全文）。外推用的是 VisNonV1 nsys，不是本刀新测。

## Don'ts

1. 勿重放 **VisNonV1 plain**（attn FP8 + 独立 `quantize_fp8`）或 **V1 plain**（拆 gelu_fp8，embed +1.5～+2.2）。
2. 勿开 **2-step**。
3. 勿把估带 −0～−2.5（中枢 −0.5～−1.5）写成已合入，也勿写成能冲满 **66.7**。
4. 勿只开瘦 `quantize_fp8` 当 Soft；无 FP8Linear 却开 `res_ln_fp8` 会在建图失败。
