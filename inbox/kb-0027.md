## 结论

来源：牛马 DitGemm-Traits design/scout（2026-10-15）；架构师批 **Soft-GO，默认不合**。**未出代码、未编 so、未合基线、未改 CURRENT。** kb-0026 批的「下一拍只 design」由本卡记下，不是实现结果。

根因：现 `Traits1Sm`（128×256×128 / 1SM）对 DiT 宽 N 软失败，回落 B2（256×128×64 / 2SM）。`try_1sm` 对 **N>1024 只试这一档**，不回落已编译的 `Traits1SmN128`（128×128×128）/ `N64`（128×64×128）。N≤1024 的门是启发式选 tileN，不是 CUTLASS 硬限。1536%256=0、6144%256=0，不是整除问题；同形 `Gu64x256_1sm` 能过，说明问题尺寸本身可 implement。失败指向 TileM=128×TileN=256×1SM 在 PerColBias 下的 smem / AccumulatorPipeline / initialize，不是编不过。

Gu64 能过但 ff0 更慢：128 发约 7.57→**8.08**（+0.51），loop **+2.14**。qkvo / ff2（N=1536）不进 GU 门。**C2**（把现有 `Gu64x256_1sm` 扩到 N≥1536）默认 **Soft-NO**。

实现序（架构师批）：先 **C0**——`try_1sm` 宽 N 改为 N128→N64→Traits1Sm→B2，零新 struct，microbench 三形 `(41,1536,1536)` / `(41,1536,6144)` / `(41,6144,1536)`。能过但不快或仍软失败，再 **C1** 新 `Traits1SmM64N128`（64×128×128 / 1SM），门 **M≤64**。M 浪费 64→41 约 36%（B2 TileM=256 约 84%）。C3 只作 C1 不足时的宽 N 备选；C4 勿首刀。

ROI 上界：乐观 Δe2e **−6～−8.5**，现实 **−2.5～−5**，悲观 **≥0**。小M税 **24.56 ms**，距 **66.7** 仍约 **20.8 ms**（SoftAdd e2e_full ~87.5，kb-0023）。乐观也只吃掉约 1/4～1/3，**吃不完**。保持 `TVM_FP8_SMALL_M_TILE=1`。下一实现刀默认仍不合，C0 出数后再批。DitAttnE4 Soft 继续 backlog（kb-0013）。

可泛化：宽 N 的 1SM 分派缺口要先用已有 tile 探针，再新开 Traits。专档能 initialize 不等于比 2SM B2 快；e2e 判决以 same-session e2e_full 为准，loop 副作用可以大于 GEMM Δ。

C0 measure 见 **kb-0028**（Soft-GO **不合**）。

## 适用条件

- 硬件：Thor；栈 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi+DitSoftAdd。SoftAdd e2e_full **~87.5**（锁值 87.506，kb-0023）。
- 模型：GR00T N1.7 DiT denoise。三形 M=41：qkvo (41,1536,1536) **8.85** / ff2 (41,1536,6144) **8.21** / ff0 (41,6144,1536) **7.50**（kb-0025）。Epi 为 PerColBias；目标 cluster 1SM。
- 先验：Tune env NO-GO（kb-0026）。`1sm` 仍 672×B2；GU ff0 更慢。本刀只读 `fp8_gemm_sm100.{cuh,cu}` 与 CUTLASS mainloop/epi `can_implement`，不重编 so。
- 保持 `TVM_FP8_SMALL_M_TILE=1`。宽 N 小 M 要在 B2 之前插入 C0/C1，避免先 B2 成功导致 1SM 永吃不到。GU 门维持 N≥4096 或保持关。
- 验证序（下一实现刀，本卡未跑）：microbench 三形记 can_implement / initialize / med µs / 选中 Traits；denoise same-session A/B（`SMALL_M=1`，lockfreq，warmup=8 iters=40）；gate overall cos>0.999 且 mse<0.0005；nsys 确认小 M 发切到目标 1SM tile、L 仍 672。
- C0 出数见 **kb-0028**（Soft-GO 不合）：新编 so 上 Traits1Sm 已能过，未落到 N128/N64；墙钟未稳赢。C1 的 64×128×128/1SM 仍未测。本卡 ROI 是设计上界，不是 C0 实测。

## 证据

见 `evidence/gr00t-ditgemm-traits-20261015/`（summary + design 全文）。根因数字来自 kb-0026 Tune nsys 与 kb-0025 Shape，本刀没有新的 denoise A/B。C0 measure 见 **kb-0028**（Soft-GO 不合）。

## Don'ts

1. 勿把 **C2**（扩展 GU 门到 N≥1536）当首刀。ff0 上 Gu64 已测更慢（+0.51 GEMM / loop +2.14）。
2. 勿把 ROI 上界写成已填上 **66.7**。乐观 Δe2e −6～−8.5 仍留 gap ~12–15；gap ~20.8 **吃不完**。
3. 勿在 **C0** microbench 出数前 commit、合基线或改 CURRENT。本刀 design only；下一实现刀默认仍不合。
4. 勿并行硬啃 **DitAttnE4** Soft；继续 backlog（kb-0013）。
5. 勿丢掉 **`TVM_FP8_SMALL_M_TILE=1`**（Tune 已钉）。
6. 勿再扫现有 env，也勿原样硬啃已证软失败的 `Traits1Sm`(128×256)。
