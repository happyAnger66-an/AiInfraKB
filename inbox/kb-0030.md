## 结论

来源：牛马 DitGemm-C1 Soft-GO + merge；架构师由 Soft-GO 升 **GO 合入**（C0 底座同刀）。C0 单独墙钟噪声、Soft-GO **不合** 仍见 **kb-0028**；本刀把 C0 wide-N 1SM dispatch 和 C1 新 Traits 合成一刀推进 synapsex。

路径：`fp8_gemm_sm100.cuh` 增加 `Fp8GemmSm100Traits1SmM64N128`（Tile `64×128×128` / Cluster `1×1×1`）。`fp8_gemm_sm100.cu` 在 BiasGelu / Bias / nobias 的 `try_1sm`、trailing 1SM ladder、BiasGeluE4m3 上 **M≤64 优先试 M64N128**，失败再走 C0 链（Traits1Sm→N128→N64→B2）。宽 N 仍先 `try_1sm` 再 B2。未改 pack，只升 GEMM so。

命中：denoise nsys **640× Traits1SmM64N128（64×128×128/1SM）** + **32× B2**（crosskv M=448）。C0 对照是 640× Traits1Sm 128×256×128/1SM。crosskv 未动。

同 session SoftAdd pack、`TVM_FP8_SMALL_M_TILE=1`、lockfreq：C0 e2e **87.694** / loop **43.026** → C1 e2e **84.893** / loop **39.797**（e2e **−2.802** / loop **−3.229**）。vs 同窗 Sep22 baseline e2e **88.255→84.893**（**−3.362**，约 **−3.36**）。GEMM nsys **24.059→21.360**（**−2.70 ms/loop**）。Micro vs C0：qkvo **−21.2%** / ff2 **−26.3%** / ff0 **−21.1%**。落 Traits ROI 现实带 −2.5～−5 的下沿～中带；乐观 −6～−8 未达。Gate C1 vs C0：cos **1.0** / mse **0** / 132/132，**bit-identical PASS**。

合入后 CURRENT 升 **+DitGemm-C1**。权威墙钟是 Soft-GO **84.893**（架构师钉 **~84.9**）。merge lockfreq sanity **85.410**（相对 Sep22 SoftAdd ref 88.128，Δ −2.718）只记抖，不压过 84.893；仍稳赢 SoftAdd ~87.5。距 **66.7** 仍 **~18 ms**。DitAttnE4 Soft 仍 backlog，**未开**。

可泛化：M=41 上 TileM=64 比 TileM=128 少浪费，墙钟可以吃到 GEMM Δ。合入数字以 Soft-GO same-session e2e_full 为准，merge sanity 另记抖。C0 命中不够合，不妨碍把 C0 dispatch 当作已赢墙钟的 C1 底座同刀提交。

## Don'ts

1. 勿未经 **晓安哥** 开 **DitAttnE4** Soft。它仍是 backlog，本刀未开。
2. 勿动 **crosskv / QK / SoftAdd**。crosskv 32 发仍 B2；pack 未改，只升 GEMM so。
3. 勿把权威 e2e **~84.9** 写成已冲满 **66.7**。距 66.7 仍 **~18 ms**。
4. 勿丢掉 **`TVM_FP8_SMALL_M_TILE=1`**。
5. 勿用 merge sanity **85.410** 压过 Soft-GO 权威 **84.893**（钉 **~84.9**）。85.410 只记抖。
