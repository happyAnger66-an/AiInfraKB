## 结论

来源：牛马 LlmRmsQ scout；架构师 **升 GO，批合**（scout 原文 Soft-GO 默认不合）。

路径：`input_layernorm`→FlashRT `rms_fp8`→q/k/v `forward_prequantized`（Qwen `*w` 用 `w−1` 适配 Gemma 核）。同 session 相对 L3+AdaStatic：**e2e −2.024 / llm −1.638**；打满 inventory 估 −0.5～−2 上沿。nsys：QKV nvjet **768→0**，`rms_fp8_kernel`×256 HIT。

与 **L2** 硬边界：L2 是 RMS FP16 + 独立 `quantize_fp8`（薄利 NO-GO）；本刀是 **RMS 直出 e4m3 共享进 QKV**。overall PASS 但 mse **4.58e-4 贴门**，合入后 sanity 须盯紧。

可泛化：QKV FP8 成败看 **入口税形态**（融合 RMS→e4m3 vs 独立 Q）；同层不同接线可差一个数量级。

## 适用条件

- 硬件：Thor；基线叠 L1+L3+D1+crosskv+D1take+AdaStatic。
- 模型：GR00T LLM（UniRT/MLC）；preset `e4m3_gr00t_llm_l3_qkv`。
- 未动：Vision、DiT、Silu epi、降步。
- 合入 sanity / 新基线锁数：待牛马 merge 报告补 evidence。

## 证据

见 `evidence/gr00t-llmrmsq-20261015/`。架构师：`w−1` 不挡合入、记 Soft-GO 可跟；下一刀 **EncFp8** scout。

## Don'ts

1. 勿重放 **L2 plain QKV**（独立 quantize）；勿把本刀写成 L2 重开。
2. 勿忽略 mse 贴门——合入后必须 lockfreq sanity。
3. 勿自批 Silu→e4m3 epi / Vision Soft-GO / DitAttnE4 核债。
4. 勿用 denoise_loop 会话噪声否决（权威 e2e_full / backbone_llm）。
