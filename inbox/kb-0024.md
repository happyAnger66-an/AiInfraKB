## 结论

来源：牛马 Vision Soft glue+measure；架构师确认 **NO-GO，不合**。kb-0021 的 Soft-GO / GO glue+measure（in flight）由本卡实测取代。

同 session SiluMul lock bb vs Soft（DiT = Cg4）：embed **18.886→19.256（+0.370）**、e2e_full **88.638→88.806（+0.168）**。scout 估中枢 **−0.5～−1.5** **符号相反**。overall cos **1.0** / mse **0** PASS，但是相对门、**不链式** embed→LLM→action；embed feature cos **0.417938**（约 **0.418**）崩，不得当 Vision 质量门。backbone_llm bit-identical（Soft 不碰 LLM）。denoise_* 抖动记会话噪声；刀账以 embed / e2e_full 为准。

nsys（embed_vision，12 profiled iters）：`res_ln_fp8` **HIT**（~3.715 ms/iter），`layer_norm*` ~1.778→~0.101。`kQuantizeHalfToE4m3` 仍 **~0.39 ms/iter** → half_in **PARTIAL MISS**（BiasFromHalf 未吃满）。nvjet f16 bias ~8.492→~0.649 **丢掉**，cutlass GEMM ~4.464→~8.703 顶上。清税不完整，且 FP8 cutlass 打不过基线 fused-f16。

勿回 VisNonV1 / V1 plain。勿把 Soft 写入 CURRENT。Thor apex_rt + LT5 工作树 Soft glue **可留实验**（未 commit、未改 CURRENT_BASELINE）。续挖数值挂 Soft backlog（real-act calib 对齐 LN→e4m3、核对 deepstack residual；再修 half_in BYOC 清掉残留 Q）。下一刀 **DitGemm-Shape（measure only）**。B1 DitSoftAdd（kb-0023）不受本结论阻塞。

可泛化：`res_ln_fp8` 上图不等于墙钟变负；half_in 没吃满时独立 Q 还在，再丢掉 nvjet f16 就会双回退。相对 overall PASS 盖不住 embed feature 崩。

## 适用条件

- 硬件：Thor（`pi05-forge-agent` / thor-2239）；`FLASHRT_ROOT=/srcs/data/FlashRT`。lockfreq gpc=1575 / nvd=1692。
- 栈：L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi。本刀 DiT 仍是 Cg4，对照是 SiluMul lock bb，未叠 DitSoftAdd。
- 模型：GR00T Qwen3 ViT。preset `e4m3_gr00t_llm_l3_qkv_enc_vit_soft`（232 = 136+96）。pack `gr00t_n17_bb_fp8_l3_qkv_rmsq_enc_silumul_vit_soft_i4_unirt`（新名字，不覆盖锁 bb alias）。
- 开关：`--fp8 e4m3_gr00t_llm_l3_qkv_enc_vit_soft --fp8-gemm --set vit_fp8_res_ln=true --set vit_fp8_o_half_in=true`。编译 env 禁 `VIT_ATTN_SHARED_FP8` / `VIT_ATTN_O_FP8` / `VIT_GELU_FP8` / V1b。
- 未动：锁 bb alias、DiT Cg4、VisNonV1 env 默认。未 commit。
- 未验证：数值修复后的 feature cos；half_in 清掉 `kQuantizeHalfToE4m3` 之后的墙钟。DitGemm-Shape 只列为下一刀，本卡没有它的测量。

## 证据

见 `evidence/gr00t-vision-soft-20261015/`（summary + measure 全文；scout 仍在同目录）。架构师：NO-GO 不合；工作树 glue 可留实验；下一刀 DitGemm-Shape measure only。

## Don'ts

1. 勿回 **VisNonV1 plain** / **V1 plain**。
2. 勿把 overall PASS 当成 Vision 质量门（embed feature cos **0.418** 已崩；门是相对、非链式）。
3. 勿把 Soft 写入 **CURRENT** / 合入基线。
4. 勿声称 Soft 填得上 **66.7**。
5. 勿开 **2-step**。
6. 勿用 denoise 会话抖动改写刀账；刀账是 embed **+0.370** / e2e_full **+0.168**。
