## 结论

来源：牛马 LlmSiluEpi design scout + merge；架构师由 Soft-GO 升 **GO glue**，批合并。**不挖 GEMM-epi。**

路径：synapsex 薄 so `silu_mul_fp8`（对齐 FlashRT `silu_mul_split_fp8_fp16`）接到 `Qwen3MLP`，`h_q = silu(gate)*up → e4m3` 再 `down.forward_prequantized`。消掉已融的 `fused_silu_multiply` 之后那次 down 入口 `quantize_fp8`。**不** merge `gate_up`，**不**新写 Silu GEMM epi（SM100 只有 GeGLU/GELU epi）。

同 session 相对 Cg4：e2e_full 90.210→**89.772**（**−0.438**），backbone_llm 18.265→17.619（**−0.646**），落 scout **−0.3～−1.0**。锁基线旧值 90.295 在本 session 抖到 90.210；权威墙钟是 cand **89.772**。denoise_loop +0.69 是 DiT 未改的会话噪声。overall cos **0.999952** / mse **1.152e-4** PASS；llm feature cos **~0.84**，**不是** bit-identical。距 66.7 仍 **~23.1 ms**。

架构师口径：合规小刀菜单到此关闭，不自批下一刀。

可泛化：L1 之后 silu×mul 已经一核，再融只值 down 入口 Q 那一截；inventory −1～−3 要按下修带报。GELU epi 不能冒充 SiLU。

## 适用条件

- 硬件：Thor；栈 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi。
- 开关：`MLC_VLA_GR00T_LLM_SILU_MUL_FP8=1` + `MLC_VLA_SILU_MUL_FP8_SO=libsynapsex_silu_mul_fp8.so`。
- bb：`gr00t_n17_bb_fp8_l3_qkv_rmsq_enc_silumul_i4_unirt`（别名 `..._SiluMul_unirt`）。DiT 仍是 Cg4，未改。
- commit：synapsex `06783a8e8384cfaf0edf687a1be30a0e236a61fa`（`feat/silu-mul-fp8`）；mlc-vla `ad3cc2bac2a4198d95fc036c1d2c9005a47f52d9`（glue）。
- 未做：merge gate_up；Silu GEMM epi；DitSoftAdd。

## 证据

见 `evidence/gr00t-llmsiluepi-20261015/`（summary + design scout + merge + `CURRENT_BASELINE-siluepi.md`）。

## Don'ts

1. 勿 merge **gate_up**，勿新挖 SM100 **Silu GEMM epi**。
2. 勿把 `geglu_fp8` / `gelu_fp8`（tanh-GELU）接成 SiLU。
3. 勿把本刀写成 bit-identical——llm feature cos ~0.84，门控看 overall。
4. 勿用 denoise_loop 正抖否决；刀账是 llm **−0.646** / e2e **−0.438**，权威墙钟 **89.772**。
5. 勿把 inventory −1～−3 或本刀当成还能冲满 66.7 的主路径。
