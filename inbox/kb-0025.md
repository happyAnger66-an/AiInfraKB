## 结论

来源：牛马 DitGemm-Shape measure；Cg4 pack nsys 逐发 `GemmUniversal`，按 cutlass grid(M,N) 聚类，同 grid 的 K 用 duration 双峰切开。**measure-only。未 Tune、未改 tile、未合基线、未改 CURRENT。**

栈已含 DitSoftAdd（e2e_full **87.506**，墙钟 denoise_loop **42.610**）。SoftAdd 只融 residual⊕LN_fp8，**不改** FP8 Linear 的形状和次数，故 **未重采** SoftAdd pack nsys。时序以 **Cg4 B1 nsys** 为准：fp8_gemm **25.43 ms/loop**，denoise GPU **45.788**，墙钟 loop Cg4 **43.95** / SoftAdd **42.61**。

静态账：self 16×6 + cross 16×4 = 160/step ×4 = **640**，加 `CROSS_KV_PRECOMP` 的 **32**，合计 **672**。实测 L **672=672**，逐发加总与 B1 fp8_gemm **25.43** 对齐，对账 **PASS**。

四 shape：**qkvo (41,1536,1536) 8.85**（384 发，34.8%）/ **ff2 (41,1536,6144) 8.21**（128，32.3%）/ **ff0 (41,6144,1536) 7.50**（128，29.5%）/ **crosskv (448,1536,2048) 0.87**（32，3.4%）。三个 M=41 小M税合计 **24.56 ms = 96.6%**。同一 256×128×64 2SM 模板下 M=41 约 **8.7–13.5 TFLOPS**，M=448 约 **104 TFLOPS**，大 GEMM 已近满血。

架构师认 Shape。批 **DitGemm-Tune GO（仅小 M）**，in flight：优先 tileM / 1SM / 已有 `TVM_FP8_SMALL_M_TILE`（本刀未动旋钮）。**禁先啃 crosskv**。**禁为这刀改 SoftAdd / QK**。本卡没有 Tune A/B，不能当合入结果，也不填距 **66.7** 的缺口（SoftAdd 后仍约 **20.8 ms**，见 kb-0023）。

可泛化：占一半以上的 FP8 GEMM 先对 (M,N,K) 再谈 tile。小 M 发数墙和已近满血的大 GEMM 不要排成同一优先。

## 适用条件

- 硬件：Thor；模型 GR00T N1.7 DiT denoise。`sa_seq=41`，`vl_seq=448`，`D=1536`，`ff_inner=6144`，`cross_dim=2048`；32 层交替 self/cross；4 step。
- 栈：L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi+DitSoftAdd。时序源是 B1 的 `cg4_denoise_loop.sqlite`，不是 SoftAdd 候选测。
- 聚类：tile 256×128、cluster 2SM。`(2,12)`→N=1536 且 M 小；`(2,48)`→N=6144；`(4,12)`→M=448。同 grid 的 K=1536 vs K=6144 用 duration 双峰（cut≈52.7 µs，高侧正好 128/loop = ff2）。
- Tune：已批仅三个 M=41，尚未做、未 commit。crosskv 仅 3.4%，低 ROI。
- 未验证：1SM / 更小 tileM 的 Δe2e 与精度；SoftAdd pack 同 session 的 GEMM µs（预期 L 与四 shape 同构，ms 噪声级，不改本结论）。

## 证据

见 `evidence/gr00t-ditgemm-shape-20261015/`（summary + 全文 + `ditgemm_shape_hist.json`）。nsys 分桶来自 Cg4 锁包。架构师认 Shape，Tune（仅小 M）in flight。

## Don'ts

1. 勿未做 Shape 账就 Tune，或大改 cutlass so。本卡 Shape 已齐；Tune 仍须另开 A/B，本卡不是 Tune 结果。
2. 勿先啃 **crosskv**（M=448 仅 **3.4%**，约 **104 TFLOPS**，已近满血）。
3. 勿为这刀改 **SoftAdd** 或 **QK**。
4. 勿把小M税 **96.6%** 或本刀写成已填上 **66.7**。
5. 勿未做 Tune A/B 就 commit、合基线或改 CURRENT。
