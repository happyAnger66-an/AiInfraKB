## 结论

2026-10-15 本机 compose 上，model_forge 无状态化主线（web W0–W5、service S1/S2、agent A1–A5）收口。状态不再只活在 web 容器里：W2 杀掉 web 容器后，本机 MySQL 里账号 **13**、presets **2**、feedback **3** 仍在。S1 把库从 sqlite 迁到 MySQL，库名 `model_forge_service`，库内 job **112**、logs **86464**、agents **4**，healthz `db_driver=mysql`。

对外工件只用一条 URI：`mfs://artifacts/<key>`。`mfs` 是 **Model Forge Storage** 的逻辑名，key 映射到 `PI05_ARTIFACT_ROOT` 的物理路径。`/work` 是本机路径，不能当可下载 URI；单测拒绝这种对外 URI。agent 在 upload 之后只采用服务端返回的 `mfs://`。A5 冒烟是 job **115** 的 `mfs://artifacts/115/a5_smoke.bin`，by-uri **200**。`pytest forge_agent` **141 passed**。web 回归覆盖登录、presets、BFF 代理，补清单没有单独通过条数。权威契约是 `model_forge_service/docs/ARTIFACT_CONTRACT.md`。

尚未真上 lab-ssr 集群，下一真实任务的控制台端到端也还要再盯。本卡不表示集群已上线。

领域 lesson 归 AiInfraKB。仓边界和一刀一功能归 agent-kit（atomic-commit PR），不写进 claim。

## Don'ts

1. 勿写成 lab-ssr 集群已上线。未做完的是真上集群，以及下一真实任务控制台端到端再盯。
2. 勿把 `/work` 本机路径当对外可下载 URI。对外唯一形态是 `mfs://artifacts/<key>`。
3. 勿漏写 `mfs`：Model Forge Storage 逻辑名，key 映射 `PI05_ARTIFACT_ROOT` 物理路径。
4. 勿把 web 回归写成带条数的全绿。补清单只给出覆盖面：登录、presets、BFF 代理。agent 侧的条数是 pytest forge_agent 141 passed。
5. 勿用提交哈希代替库内计数或 by-uri 状态码。
