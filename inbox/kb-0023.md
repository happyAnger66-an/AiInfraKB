## 结论

来源：牛马 DitSoftAdd merge；架构师由 B1 epic 升 **GO glue**，批合并。Soft scout「无现成 residual+LN_fp8 核」**已过时**：核是 mlc-vla 里的 **`flashrt.res_ln_fp8`**，本刀 glue，不挖新核，也不挖 DitGemm。

路径：`BasicTransformerBlock.forward` 在 `MLC_VLA_GR00T_DIT_SOFTADD=1` 时走 `flashrt.res_ln_fp8(hidden, attn_out, …)`，再 `ff.forward_from_prequant`；失败回落 add + `layer_norm_fp8`。消的是 add2 与紧随的 LN→e4m3。QK / softmax / PV 未动。`strings model.so`：cand `flashrt_res_ln_fp8`×19，ref×6。

同 session 相对 Cg4+SiluEpi：e2e_full 88.155→**87.506**（**−0.649**），denoise_loop 44.249→42.610（**−1.639**），denoise_step **−0.770**。落 scout **−0.2～−0.8** 的中上。loop 降幅高于 add2 GPU 天花板 ~1.37，含 launch，墙钟合理。锁基线旧值 89.772 在本 session 抖到 ref 88.155；权威墙钟是 cand **87.506**（≈11.43 Hz）。embed_vision +0.198、backbone_llm +0.223 是 bb 未改的会话噪声。overall cos **1.0** / mse **0** / 132/132，**bit-identical PASS**。距 66.7 仍 **~20.8 ms**。

kb-0018 的「softmax 已融、与 residual add 不相邻」仍然成立；被取代的是「无核、默认不合、本轮无代码」。

可泛化：相邻的 residual add 与 LayerNorm→e4m3 可以用现成 `res_ln_fp8` glue，不必先写新核。刀账看 denoise，不看 vision/llm 抖动。

## 适用条件

- 硬件：Thor；栈 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi+DitSoftAdd。
- 开关：`MLC_VLA_GR00T_DIT_SOFTADD=1`，叠在 AdaStatic+Cg4 上。`num_inference_timesteps=4`，禁 2-step。
- DiT：`gr00t_n17_dit_fp8_full_dit_phase_ada_ln_d1_crosskv_take_fuse_adastatic_cg4_softadd_unirt`（别名 `..._Cg4_SoftAdd_unirt`）。pre-SoftAdd 仍指向 `..._adastatic_cg4_unirt`。bb 仍是 SiluMul，未改。
- commit：mlc-vla `03604486355c84939f1133a0af05c1833bff1f3a`（短 `03604486`，`feat/gelu-fp8-synapsex`，已 push）。未碰 synapsex。

## Don'ts

1. 勿动 **QK / softmax / PV**，勿把 PV 算进这刀的收益。
2. 勿在本轮挖 **DitGemm**。
3. 勿用 embed_vision / backbone_llm 的正抖否决；刀账是 denoise_loop **−1.639** / e2e **−0.649**，权威墙钟 **87.506**。
4. 勿把 kb-0018「无核、默认不合」当成仍成立。
5. 勿把 −0.649 或基线 ~87.5 写成能冲满 **66.7**。
