## 结论

来源：牛马 B1 Denoise 硬啃开题；Cg4 pack nsys 分桶。**未 wire、未编新 pack、不合基线。** 只交设计 + nsys。晓安哥拍 **B1+B2**；本卡只覆盖 B1。

锁栈 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi：e2e_full **89.772**，墙钟 denoise_loop **43.953**，nsys GPU **45.788 ms/loop**。主墙是 FP8 cutlass GemmUniversal **25.430**（**55.5%**，L=672），layout **8.236**（18.0%），QK/softmax/add 约 **7.2**。Cg4 把墙钟 loop 从约 49.2–49.7 收到 **43.953**，内核桶几乎同构（对照 AdaStatic nsys GPU 46.645）。B1 要啃的是内核工作量。gap ≈ **23.1 ms**（相对 66.7）。

Epic 三刀：`DitGemm`（25.4 ms 主墙）/ `DitSoftAdd`（add2 **1.366** 与 `layer_norm_fp8` **0.666** 相邻）/ `DitAttnE4`（quantize **0.379**）。推荐第一刀 **DitSoftAdd**：`flashrt.res_ln_fp8` 已在（`res_ln_fp8_kernel_f16`；DiT hidden=1536 走 generic），本刀 **glue、不挖新核**。这修订 kb-0018「无现成 residual+LN_fp8 核、今日不可测」——核已 vendored，SoftAdd 从「不挖核」升到可 glue。单刀估仍是 **−0.2～−0.8**。

估合计 Δe2e：现实 **−1～−4**；乐观（含 DitGemm 大成）**−3～−10**。单 epic 填不满 ~23 ms。**DitGemm 后置**（先 Shape 账，再谈 tile）。架构师口径：**GO SoftAdd first**。

可泛化：开题先锁 GPU 分桶再排刀。相邻的 add+LN 用现成核 glue；占一半以上的 GEMM 先拆形状，不盲调 so。

## 适用条件

- 硬件：Thor（thor-2239 / `pi05-forge-agent`）；`FLASHRT_ROOT=/srcs/data/FlashRT`。验收 e2e_full；overall cos>0.999 且 mse<0.0005。
- 模型：GR00T DiT denoise。Capture `..._adastatic_cg4_unirt`，warm3 / iters12 / lockfreq。SiluEpi 不改 DiT。
- 排序：DitSoftAdd glue → DitAttnE4 → DitGemm-Shape → DitGemm-Tune。DitGemm-Shape 可与 SoftAdd 并行 measure，不合入。
- SoftAdd 成功门槛（若落地）：add2 L 64→0；`layer_norm_fp8` 与 `res_ln_fp8` 此消彼长；softmax/QK/PV 不变；same-session Δe2e ≤ −0.2 才算正；flag=0 回落旧路径。
- 未验证：glue 后的 lockfreq A/B 与 gate；DitAttnE4 新核 `dit_pack_out_fp8`；DitGemm 的 (M,N,K) 直方图与 tile。
- kb-0018 的「softmax 已融、与 add 不相邻」仍然成立；被修订的只是「无核」。

## 证据

见 `evidence/gr00t-b1-denoise-epic-20261015/`（summary + 开题全文）。nsys 分桶来自 Cg4 锁包，不是 SoftAdd 候选测。

## Don'ts

1. 勿开 **2-step / 减步**。
2. 勿重放 VisNonV1 / V1 plain / L2 / AttnScore / DitLayout。
3. 勿把 kb-0018「无核、不挖核」当成 `res_ln_fp8` 仍不存在；也勿把 SoftAdd 误融 softmax 或吞 PV。
4. 勿未做 Shape 账就大改 cutlass so。DitGemm 后置。
5. 勿把现实 −1～−4 或乐观 −3～−10 写成能到 **66.7**。
