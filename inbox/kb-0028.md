## 结论

来源：牛马 DitGemm-C0 measure；架构师认 **Soft-GO，不合**。kb-0027 批的 C0（dispatch 拓宽，零新 struct）由本卡出数。**未合基线、未 commit、未改 CURRENT。** C0 工作树与实验 so **留底座**。批 **C1 `Traits1SmM64N128` GO in flight**。

C0 改的是 `fp8_gemm_sm100.cu`（+93/−20，未 commit）：宽 N `try_1sm` 在 Traits1Sm 失败后续 **N128→N64**；mode=1 宽 N **先 `try_1sm` 再 `try_b2`**（否则 B2 先成功，1SM 永吃不到）。未新开 Traits struct。

同 session 锁频，SoftAdd pack，`TVM_FP8_SMALL_M_TILE=1`。baseline so 是 unified Sep22；C0 so 为本刀新编（`FP8_CUDA_ARCH=110a`）。CURRENT 锁值仍是 SoftAdd e2e_full **87.506**（~87.5）；本窗 baseline e2e **87.680** / loop **44.085**，刀账以同窗 Δ 为准。

| tag | e2e_full | denoise_loop | Δe2e | Δloop |
|---|---:|---:|---:|---:|
| baseline | **87.680** | **44.085** | 0 | 0 |
| **C0** | **87.529** | **44.152** | **−0.151（约 −0.15）** | **+0.067（约 +0.07）** |

nsys（denoise_loop，12 profiled iters）：

| tag | tile / cluster | L/loop | ms/loop |
|---|---|---:|---:|
| baseline | B2 **256×128×64 / 2SM** | **672** | **25.823** |
| C0 | **Traits1Sm 128×256×128 / 1SM** | **640** | **23.958** |
| C0 | B2 256×128×64 / 2SM（crosskv M=448） | **32** | **0.871** |
| C0 合计 | — | **672** | **24.829**（Δ **−0.994**，约 **−0.99**） |

1SM 命中 **YES**：640/672 是小 M 三形，crosskv 32 发仍 B2。选中的是 **Traits1Sm**，不是 N128/N64。意外：kb-0027 记的「Traits1Sm 对 DiT 宽 N 软失败」对的是 **Sep22 旧 so**（Tune `1sm` 仍 672×B2，见 kb-0026）；**本刀新编 so 上 Traits1Sm 已能 initialize**，回落档本 session **未触发**。C0 吃上 1SM 的关键仍是 mode=1 宽 N 先 `try_1sm`。

Microbench（Bias+PerCol，三形，`SMALL_M=1`）：qkvo (41,1536,1536) 21.8→**18.6**（−14.5%）；ff2 (41,1536,6144) 43.0→**30.8**（−28.3%）；ff0 (41,6144,1536) 41.0→**27.8**（−32.1%）。tile 均为 128×256×128 **1SM**（基线 256×128×64 **2SM**）。

墙钟没吃满 GEMM Δ：e2e **−0.15** 与 loop **+0.07** 都在噪声带，loop 甚至略正。denoise_step −0.286、e2e_head −1.174、vision/llm/enc 记会话噪声，**刀账是 e2e_full / denoise_loop**。Gate overall cos **1.0** / mse **0** / mean_abs **0** / max_abs **0** / 132/132，**bit-identical PASS**。

不合、不 commit、不改 CURRENT。TileM=128 对 M=41 仍浪费约 68%，架构师批下一刀 **C1 `Traits1SmM64N128`**（64×128×128/1SM，门 M≤64）**GO in flight**；本卡没有 C1 代码和 C1 数。保持 `TVM_FP8_SMALL_M_TILE=1`。勿动 crosskv（M=448 仅 3.4%，见 kb-0025）。距 **66.7** 仍约 **20.8 ms**（kb-0023）；GEMM −0.99 / e2e −0.15 **填不上**。

可泛化：新编 so 上旧 Traits 能 initialize，不等于 design 里的回落档会跑到，也不等于墙钟稳赢。e2e 判决以 same-session e2e_full 为准；GEMM −1 ms 可以被图内噪声盖住。

## 适用条件

- 硬件：Thor（`pi05-forge-agent` / thor-2239）；`FLASHRT_ROOT=/srcs/data/FlashRT`。lockfreq。栈 L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi+DitSoftAdd。
- so：baseline `/srcs/tvm-relax/build/lib/libtvm_fp8_gemm_unified.so`（Sep22）；C0 `/work/phase_a_so/libsynapsex_fp8_gemm_c0.so`。源码 `synapsex/operators/fp8_gemm/fp8_gemm_sm100.cu` 未 commit；本地 bak `fp8_gemm_sm100.cu.c0bak`。
- 模型：GR00T N1.7 DiT denoise。三形 M=41：qkvo (41,1536,1536) / ff2 (41,1536,6144) / ff0 (41,6144,1536)。crosskv (448,1536,2048) 仍 B2。
- 对照：同 SoftAdd pack、同 session、`SMALL_M=1`。未合入、未改 `CURRENT_BASELINE.md`。
- 未动：crosskv、QK、SoftAdd、softmax、PV、GU 门；未 2-step；未 VisNonV1/V1/L2/AttnScore/DitLayout；未并行 DitAttnE4；未开 C1 代码。
- 未验证：C1 `Traits1SmM64N128`（64×128×128/1SM）的 µs 与 Δe2e。更长 A/B 能否把 e2e −0.15 / loop +0.07 收成稳定墙钟赢。本卡 ROI 不是 kb-0027 的设计上界。

## 证据

见 `evidence/gr00t-ditgemm-c0-20261015/`（summary + measure 全文）。Traits design 是 kb-0027；Tune NO-GO 是 kb-0026；Shape 是 kb-0025；SoftAdd 锁值 87.506 是 kb-0023。架构师：Soft-GO 不合；C0 留底座；C1 GO in flight。

## Don'ts

1. 勿用墙钟噪声合 C0。e2e **−0.15** / loop **+0.07** 未稳赢；GEMM **−0.99** 不是合入门槛。
2. 勿动 **crosskv**（32 发仍 B2；M=448 仅 **3.4%**）。
3. 勿把 GEMM −0.99 或 e2e −0.15 写成已填上 **66.7**。距 66.7 仍约 **20.8 ms**。
4. 勿丢掉 **`TVM_FP8_SMALL_M_TILE=1`**。
