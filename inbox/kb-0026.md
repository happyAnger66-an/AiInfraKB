## 结论

来源：牛马 DitGemm-Tune env A/B；架构师确认 **NO-GO，不合、不 commit**。kb-0025 批的 Tune（仅小 M）由本卡实测关闭。

SoftAdd 栈现 env 已是 `TVM_FP8_SMALL_M_TILE=1`。本刀只拧 env（`auto` / `1sm` / `GU=1` / `1sm+GU` / `SKIP_2SM` / `legacy=0`），**不重编 pack、不改 so**。同 session 锁频 baseline：e2e **88.128** / loop **42.764**。CURRENT 锁值仍是 SoftAdd **87.506**（~87.5）；88.128 是本窗会话抖，刀账以同窗 Δ 为准。

| tag | Δe2e | Δloop |
|---|---:|---:|
| auto（≡ mode 1） | −0.062 | −0.003 |
| **1sm** | **+0.406（约 +0.41）** | +0.164 |
| **GU=1** | **+0.352（约 +0.35）** | **+2.141（约 +2.14）** |
| 1sm+GU | +0.914 | +2.356 |
| SKIP_2SM | +0.454 | +1.631 |
| legacy=0 | +0.109 | −0.275 |

auto 的 −0.062 与 legacy 的 loop −0.275 / e2e +0.109 都在噪声带，不构成赢。没有更快的 cand。

nsys（denoise_loop，12 profiled iters）：`1sm` 核名仍是 `SM100_MMA_F8F6F4_2x1SM`，tile 256×128，cluster 2×1，**672×B2** 与 baseline 同构。`Traits1Sm`（128×256）对 N∈{1536,6144} **can_implement 失败**，回落 B2。`GU_TILE=1` 把 ff0 `(41,6144,1536)` 128 发切到 `Gu64x256_1sm`（64×256×128 / 1SM；IsGuFp8Shape: M≤64 ∧ N≥4096）。这 128 发原 B2 ≈7.57 ms，GU 后 **8.08 ms**（med 62 µs）；墙钟 loop **+2.14**（含非 GEMM 副作用）。qkvo / ff2（N=1536）不进 GU 门，`1sm` 也吃不到，小M税主体未被动。

精度：各 cand vs baseline env overall cos **1.0** / mse **0** / 132/132 **PASS**，bit-identical。tile 切换不改 SoftAdd pack 数值，PASS 对速度决策无意义。

保持 `TVM_FP8_SMALL_M_TILE=1`。不合基线、不 commit、不改 CURRENT。下一拍 **DitGemm-Traits design/scout only**：要能 can_implement `(41,1536,*)` / `(41,6144,1536)` 的 1SM Traits，并给 ROI 上界；**先不出代码**。DitAttnE4 Soft 仍 backlog（kb-0013）。本刀不填距 **66.7** 的缺口（SoftAdd 后仍约 **20.8 ms**，见 kb-0023）。

可泛化：现有 env 档位对这三个 M=41 要么 can_implement 失败回落现核，要么专档比 B2 更慢。小M税要新 Traits，不是再拧 `TVM_FP8_SMALL_M_TILE` / `GU_TILE` / `SKIP_2SM`。

## 适用条件

- 硬件：Thor（`pi05-forge-agent` / thor-2239）；`FLASHRT_ROOT=/srcs/data/FlashRT`。lockfreq gpc=1575 / nvd=1692 GATE PASS。warmup=8，iters=40。
- 栈：L1+L3+LlmRmsQ+EncFp8+D1+crosskv+D1take+AdaStatic+Cg4+LlmSiluEpi+DitSoftAdd。so：`/srcs/tvm-relax/build/lib/libtvm_fp8_gemm_unified.so`（LD_PRELOAD；含 `TVM_FP8_SMALL_M_TILE` / `GU_TILE` / `SKIP_2SM`）。
- 模型：GR00T N1.7 DiT denoise。三个小M税 shape：qkvo `(41,1536,1536)`、ff2 `(41,1536,6144)`、ff0 `(41,6144,1536)`（kb-0025）。
- 对照：同 SoftAdd pack、同 session、各 cand env 对 `SMALL_M=1`。未重编 pack、未改 so、未合入、未改 `CURRENT_BASELINE.md`。
- 未动：crosskv、QK、SoftAdd、softmax、PV；未 2-step；未 VisNonV1/V1。
- 未验证：能 can_implement 上述 shape 的新 1SM Traits 的 Δe2e 与 ROI 上界（下一拍只 design/scout，本卡没有那组测量）。

## 证据

见 `evidence/gr00t-ditgemm-tune-20261015/`（summary + 全文）。Shape 先验是 kb-0025。架构师：NO-GO；保持 `SMALL_M_TILE=1`；下一拍 DitGemm-Traits design/scout only，先不出代码。

## Don'ts

1. 勿再扫现有 env（auto / 1sm / GU / 1sm+GU / SKIP_2SM / legacy=0）指望抠出小M税。
2. 勿 commit Tune cand，勿合基线，勿改 CURRENT。保持 `TVM_FP8_SMALL_M_TILE=1`。
3. 勿先啃 **crosskv**（M=448 仅 **3.4%**，见 kb-0025）。
4. 勿并行硬挖 **DitAttnE4**；Soft 仍 backlog（kb-0013）。
5. 勿把本刀或小M税 **96.6%** 写成已填上 **66.7**。
6. 勿抬 `CUTLASS_MIN_M`；勿为这刀重开 SoftAdd / QK / PV。
