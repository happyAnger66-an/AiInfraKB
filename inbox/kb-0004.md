## 结论

来源：牛马 @ LT5CG3344QDF / Thor 2026-10-14 一轮（ingest 入库，未晋升 cards）。

UniRT/MLC 路径上 `FP8Linear.forward` 对 half 激活先发独立 `quantize_fp8`，再 GEMM；full DiT 下该税可占 denoise_step **~15%+**。消税模式：

```
x_half → [fused_op → e4m3] → FP8Linear.forward_prequantized(x_q)
```

本轮落地 `gelu_fp8` / `layer_norm_fp8` / `ada_ln_fp8`（synapsex 通用核 + mlc-vla 图侧接线）。phase_ada_ln 相对 FP16 temb_fix：**denoise_loop 1.26×**，**e2e_full 1.13×（137.7→121.4 ms）**；quantize 税降至 **1.64% / 0.225 ms**。精度：full/ada_ln **26/32**；交付精度轨仍看 qkv24 **32/32**。

边界硬规则：synapsex **只**放通用核，禁止 `gr00t`/`dit` 模型名与 DiT 调度；DiT glue 留 mlc-vla。GR00T AdaLN 是 LayerNorm+(1+scale)+shift，**不能**照搬 π0.5 的 `ada_rms_fp8`。

## 适用条件

- 硬件：Thor 锁频测速（本卡数字来自 gpc=1575 / nvd=1692）。
- 模型：GR00T N1.7 DiT denoise（UniRT/MLC + FlashRT）。
- 精度：FP8 激活 Q（静态 per-tensor /act_scale，clip ±448）+ `forward_prequantized`。
- Env 门（mlc-vla，默认开）：`MLC_VLA_GR00T_FFN_GELU_FP8`、`ATTN_OUT_FP8`、`QKV_SHARED_FP8`、`FFN_LN_FP8`、`ADA_LN_FP8`。
- `ADA_LN_FP8` 启用时跳过对该 `x_q` 的 B3 shared `quantize_fp8`；cross encoder K/V 仍走 shared Q。
- Hybrid e2e：ViT/LLM 用 FP16 pack，DiT 用 FP8 ada_ln 包；升基线须 stages+e2e **且** overall+per-dim。
- 未验证：非 Thor、非 GR00T DiT、动态 scale、把领域 glue 塞进 synapsex。

## Don'ts

1. Thor 容器 `MLC_VLA_FLASHRT_ROOT` 勿指空挂载 `/srcs/FlashRT`，须 `/srcs/data/FlashRT`。
2. 勿在 loader 里把 float8 权重 `astype` 成 e4m3 却无 scale。
3. 勿把 AdaLN 当成 `ada_rms`。
4. 勿用 denoise-only 升全链路基线。
5. 速度轨 ≠ 精度轨（26/32 vs qkv24 32/32）。
6. synapsex 不写 DiT glue。
